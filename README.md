# Apêndice C da central OTEC de Nacala

Suplemento digital com os ficheiros EES do trabalho de licenciatura em Engenharia Mecânica de Artiel Marcelina Martins Rungo, Universidade Eduardo Mondlane.

## Publicação no GitHub Pages

1. Criar um repositório público na conta responsável pelo suplemento. Nome sugerido: `otec-nacala-apendice-c`.
2. Carregar o conteúdo deste pacote na raiz da branch `main`. Confirmar que `index.html` está na raiz e os dois ficheiros TXT estão em `codigo/`.
3. Em **Settings → Pages**, seleccionar **Deploy from a branch**, `main` e `/ (root)`. Guardar.
4. Depois da publicação, abrir **Visit site**, testar os dois links de descarga e copiar o URL público apresentado para a Secção C.3.

## Texto para a Secção C.3 depois da publicação

O código da simulação no EES encontra-se disponível para consulta e descarga no suplemento digital do trabalho. A página reúne o modelo principal e o ficheiro de cálculo da produção anual.
